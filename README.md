# Vértice — oficina de precisão

Landing page de uma oficina de luxo (marca fictícia) em "scroll cinematográfico":
roda de carro 3D procedural em Three.js, portal do cliente em celulares 3D, florescer
de partículas e galeria que a câmera atravessa.

Site estático, sem build: abra `index.html` por um servidor local
(`python -m http.server`) ou pelo GitHub Pages.

- Motor: modelo `cinema-scroll` da biblioteca NOVA FX (`engine/`, `fx/`)
- Conteúdo: `index.html`, `theme.css`, `site.js`
- Fotos: Pixabay (licença livre, ver `img/CREDITOS.txt`); algumas mostram marcas de
  montadoras e não devem ser usadas de forma que sugira patrocínio

Estudo de interface.
